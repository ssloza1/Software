# Software
Implemente el código para algoritmos de ordenamiento en su lenguaje de programación usando el Strategy Patterns (Fig. 5). Para la selección del algoritmo, suponga que el ordenamiento de burbuja es adecuado para arreglos de tamaño entre 2 y 6, el ordenamiento por inserción es adecuado para tamaños entre 7 y 10, y el ordenamiento rápido es adecuado en cualquier otro caso, es decir, tamaños de arreglos mayores a 11 (debe controlar que el número de elementos sea mayor que 1). Use una interfaz gráfica de usuario para ingresar los elementos a ordenar. El sistema recibe como entrada: los elementos a ordenar, ya sea en un campo de texto separado por comas, o cualquier otra opción que prefiera usar en la GUI. Cuando el array/list de elementos está ordenado, la siguiente información se muestra en la ventana (puede usar una tabla/campo de texto/etiqueta/o cualquier otro widget) y se guarda en su colección de base de datos MongoDB Atlas: la lista de números del arreglo sin ordenar, el tamaño del arreglo, el algoritmo elegido y la lista ordenada de números. Por ejemplo, si la entrada fuera 5, 8, 7, 2, la colección de la base de datos contendrá: {"unsorted":"5, 8, 7, 2","size": 4, "sort algorithm":"InsertionSort","sorted": "2,5,7,8").
